# Clearn — launch kit (design)

The brand and launch designs for Clearn, made in Claude Design (canvas "Clearn — Launch kit", decision D-68 in the
study app). The landing page in this repo is built from them.

- **Live canvas:** https://claude.ai/artifact/VSv1jo3KFC8e1HxUnAGr72 (private to the owner's claude.ai account)
- `source/` — the canvas files (`*.dc.html` boards + `canvas.json`). Their images point to the canvas asset store, so
  open them on the canvas, not in a browser.
- `previews/` — a JPG of each board, rendered from the same files with the real screenshots.

Brand "Kernel Notebook": dot-grid paper, ink `#141922`, teal `#0A6E6A`, amber highlighter `#F0B44C`, night `#0D1117`,
IBM Plex Sans / Sans Arabic / Mono. Logo = three rising bars = Clear it · Learn it · Earn it.

Rules: real screenshots and real counts only (Fall 2026–27, counted 29 Oct 2026), no price claims, no semester number,
no university logo, "independent student project".
